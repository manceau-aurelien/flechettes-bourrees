# 🍺 Fléchettes bourrées

Jeu de fléchettes (301) en un seul fichier HTML, à 1 ou 2 joueurs. Visez malgré le viseur qui tangue et la vision double !

- Cliquez pour lancer : la fléchette part toujours au centre du viseur.
- Maintenez Espace pour vous concentrer : le viseur bouge un peu moins (barre qui se vide et ne se recharge pas)..
- Finissez exactement à 0, sinon c'est un « bust ».

Sur téléphone : glissez sur le rond jaune pour viser, relâchez pour tirer ; le bouton 🧘 sert à se concentrer.

Ouvrez `index.html` dans un navigateur pour jouer.

## Jouer à deux sur internet

Dans l'écran d'accueil, chaque joueur entre le **même code à 4 chiffres** puis clique sur « Jouer en ligne » : le premier crée la salle (Joueur 1), le second la rejoint (Joueur 2). La connexion est directe entre les deux navigateurs (WebRTC via PeerJS).
