# 🍺 Fléchettes bourrées

Jeu de fléchettes (301) en un seul fichier HTML, à 1 ou 2 joueurs. Visez malgré le viseur qui tangue et la vision double !

- Cliquez pour lancer : la fléchette part toujours au centre du viseur.
- Maintenez Espace pour vous concentrer : le viseur bouge un peu moins (barre qui se vide et se recharge). Bull vert (25) = +50 % de barre, bull rouge (50) = barre pleine.
- Finissez exactement à 0, sinon c'est un « bust ».

Ouvrez `index.html` dans un navigateur pour jouer.
